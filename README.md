# Mouser

Маленькая программа для Windows: если вы не трогаете мышь и клавиатуру 3 минуты, она начинает водить курсор кругами и останавливается, как только вы вернётесь. Компьютер при этом не засыпает и не гасит экран, а программы, которые следят за активностью, видят обычные движения мыши.

## Установка

Скачайте `mouser.exe` со страницы [последнего релиза](https://github.com/catxeon/mouser/releases/latest) и запустите. Устанавливать ничего не нужно, права администратора не требуются.

У файла нет цифровой подписи, поэтому Windows SmartScreen может показать предупреждение.

## Как пользоваться

После запуска в трее, возле часов, появляется значок:

| Цвет | Состояние |
|---|---|
| Зелёный | ждёт, пока вы станете неактивны |
| Оранжевый | двигает курсор |
| Серый | пауза |

Меню по правой кнопке:

- **Пауза** — временно отключить, например на время фильма.
- **Ждать неактивности** — 1, 3, 5 или 10 минут. Выбор действует до выхода из программы.
- **Выход**.

## Поведение

- Курсор движется непрерывно по кругу радиусом 200 пикселей, один оборот за 3 секунды. У края экрана круг сдвигается внутрь.
- Любой ввод пользователя сразу останавливает движение, курсор остаётся на месте. Отсчёт начинается заново.
- Программа ничего не сохраняет: ни файлов, ни записей в реестре. При каждом запуске интервал равен 3 минутам.
- Нажатия клавиш программа не читает и не записывает, она замечает только сам факт ввода, и только пока двигает курсор.

## Ограничения

- Полноэкранные видео, игры и презентации не исключаются: для них есть пауза.
- Пока программа двигает курсор, компьютер не уснёт, в том числе от батареи.
- На экране блокировки и при запросе UAC Windows не принимает такой ввод, программа ждёт.
- Если активно окно, запущенное от администратора (например, Диспетчер задач), Windows может не дать двигать курсор.

## Сборка

Нужна 64-битная Windows с .NET Framework 4 (в Windows 10 и 11 он встроен). Отдельный компилятор ставить не надо:

```
build.bat
```

Если `mouser.exe` запущен, перед сборкой его нужно закрыть. Радиус и скорость заданы константами в начале класса `CircleMover` в `mouser.cs`.

Проверено на Windows 10.
